# Portfolio, To-Do & Product Directory Hub

A modern multi-feature web application built using React, TypeScript, and Vite. This project combines a personal portfolio, a task management system, and a product directory into a single responsive web experience.

## 🌐 Live Demo

**Live Website:**
https://spiffy-sprinkles-4b84d3.netlify.app/

## 🚀 Features

### Portfolio Section

* Personal profile showcase
* Skills and experience display
* Responsive design
* Modern UI/UX

### To-Do List

* Add tasks
* Delete tasks
* Mark tasks as completed
* Simple and user-friendly interface

### Product Directory

* Product listing page
* Product cards with details
* Category-based organization
* Clean and responsive layout

## ⚡ Installation

1. Clone the repository

```bash
git clone <repository-url>
```

2. Navigate to the project folder

```bash
cd project-folder
```

3. Install dependencies

```bash
npm install
```

4. Start development server

```bash
npm run dev
```

5. Build for production

```bash
npm run build
```
